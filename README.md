## 📋 What Was Built

### 🔍 Step 1 — EDA + Data Profiling
13 analytical questions covering:
- Structural missing value analysis (`paid_date` null rate: 0% → 75.7% across DPD buckets)
- Portfolio default rate: **38.06%** across 40,000 loans
- Credit band concentration: 600–650 band = 30% of book, NPA rate **55.46%** (1.46x portfolio)
- DPD stress ratio: MOB 4–6 shows **4.08x** higher mean DPD vs MOB 1–3
- Partial payment clustering: **32.9%** partial rate in pre-default window vs 9.1% baseline (**4x uplift**)
- City tier analysis: Tier-2 decline rate **1.62x** Tier-1 (Z=24.94, p<0.001)

### 📅 Step 2 — Vintage Analysis (BigQuery)
- Cohort loans by disbursal month (Jan 2024 – Jan 2026, 25 cohort months)
- Tracked DPD30+ rate at each MOB up to MOB12
- Worst cohort at MOB6: **65.85%**
- Avg MoM DPD30 acceleration: **6.06pp**

### 🔄 Step 3 — Roll Rate Matrix (BigQuery)
- DPD bucket transitions: Current → DPD1-29 → DPD30 → DPD60 → DPD90
- DPD30 cure rate: **40.59%**
- DPD30 → NPA roll rate: **8.36%**

### ⚡ Step 4 — Behavioral Risk Signals
Pre-default window (T-30 to T-0) vs baseline (T-120 to T-90):
- 4 signals: decline spike, amount drop, UPI shift, category diversity drop
- 33,183 DPD30 events identified
- **76.7% went transaction-silent** pre-default — strongest behavioral signal
- 50.3% of loans fire 2+ signals simultaneously in the pre-default window

### 🎯 Step 5 — Rule-Based Risk Scoring

| Tier | Loans | Default Rate | Multiplier |
|---|---|---|---|
| 🟢 Low | 21,360 (53.4%) | 27.79% | 0.73x |
| 🟡 Medium | 14,490 (36.2%) | 42.31% | 1.11x |
| 🔴 High | 4,150 (10.4%) | 72.70% | **1.91x** |

**2.62x separation** between High and Low risk tiers without any ML.

### 📊 Step 6 — Looker Studio Dashboard
- **Page 1 — Portfolio Overview:** KPI cards, loan distribution, default by band, city NPA, channel mix
- **Page 2 — Vintage & Cohort Heatmap:** Cohort × MOB matrix with conditional formatting
- **Page 3 — Roll Rate Matrix:** Transition matrix, cure rates, roll forward rates
- **Page 4 — Risk Segments:** Tier distribution, score histogram, high-risk account drillthrough

| # | Finding |
|---|---|
| 1 | 📅 **MOB 4–6 is the peak stress window** — 4.08x higher DPD vs MOB 1–3 |
| 2 | 📉 **600–650 band drives disproportionate NPA** — 30% of book, 55.46% NPA rate |
| 3 | 🔇 **Transaction silence is the strongest pre-default signal** — 76.7% of defaulters go silent 30 days before DPD30 |

## 🚀 How to Run

```bash
# 1. Clone the repo
git clone https://github.com/your-username/fintech-risk-analytics.git
cd fintech-risk-analytics

# 2. Install dependencies
pip install pandas numpy matplotlib seaborn scipy sqlalchemy pymysql faker

# 3. Run data generation
python data_generation/generate_data.py

# 4. Run notebooks in order
# notebooks/02_eda_risk_profiling.ipynb
# notebooks/03_risk_signals.ipynb
# notebooks/04_risk_scoring.ipynb

# 5. Upload CSVs to BigQuery and run SQL views
# sql/vw_vintage_dpd.sql
# sql/vw_roll_rates.sql
```
